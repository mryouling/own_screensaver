Where do I find this address?
  1. Apple Calendar (iCloud): in the Calendar app, Control-click the calendar → Share Calendar… → tick Public Calendar → copy the link.
  2. Outlook: Settings → Calendar → Shared calendars → Publish a calendar → copy the ICS link.
  3. Google, without signing in: calendar.google.com → Settings → your calendar → Integrate calendar → Secret address in iCal format.

Anyone with the address can read that calendar, so it's stored only on this Mac and never shown on the lock screen. Work accounts sometimes have this address turned off by an admin.
